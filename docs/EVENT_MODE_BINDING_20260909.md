## 修复目标

上轮方法比较句的误过滤已修复，但原样保留的三个现场授课对照仍全部漏荐：主题和本人授课经历能读取，紧随课程的“本人作为主讲教师在教室现场面授”却没有进入对应课程的形式字段。方法说明又被事件解析器的另一层否定检查拦住。

本轮保持这三条需求、九份资料及正反人选不变，没有删除现场条件或改写成更容易通过的问题。另保留PD42原始复杂需求和19份真实简历的历史对照。

## 改动与约束

- `InstructorMode`增加完整、原文可定位的本人授课形式声明解析。只接受明确本人／我／该讲师／该教师的限定语法，计划、协助、他人、引用、另一课程等不被接受。形式声明自身不能创造课程、主讲角色或过去已完成经历。
- `NarrativeTeachingEvents`仅把声明绑定到同一段中已经建立、具有明确授课人的课程事件。原文演员与形式分别保存字面字段；冲突形式、未知上下文和后续否定继续阻止准入，不跨段借用前后课程信息。
- 学员练习及上轮已限定识别的完整方法描述只保存为背景关系，不生成讲师形式、对象、次数、资格或完成事实。事件层仅不再将那个已识别的反馈比较分句当作否定履历，其他否定检查保留。
- `TeachingEvents`不把含该比较分句的完整事件重新送入正向检索。事实字段仍可核对，语义输入继续采用worker已保留的连续正向原文，避免通过事件通道重新引入被排除的反馈用语。
- 没有修改模型权重、历史标签、课程领域词典、交通排序或等级规则；Python worker与其余冻结源码不变。
