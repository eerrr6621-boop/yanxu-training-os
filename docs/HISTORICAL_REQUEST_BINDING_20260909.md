# 带授课对象及形式的历史需求绑定

这是需求解析与业务约束修复，不是后训练结果、盲测准确率或上线公告。

## 真实问题与修复

原始复杂需求中的“先示范、让新人复做、再给动作反馈”原先被拆为三个残缺主题；“本人以前在现场给带教师傅完整教过”未绑定到主题。现在保留一个完整引号对象，将本人、过去授课、完整完成、授课对象和现场／远程形式绑定到同一个课程要求。

规则只识别有界语法，不查询领域词表、模型分数或候选答案。支持中文引号、直引号、书名号及带标点的对象，保留原文字段与 Unicode 位置；引号中的“完整”“独立”“现场”等词不能创造外围经历条件。未知限定、错配引号、安排他人、计划、含多个对象的歧义不能被吞掉。原已支持的简单书名号经历句继续由原解析路径处理。

业务校验使用同一课程的授课对象与讲师授课形式，不允许另一课程的现场经历或学员在教室练习来补足要求。过去讲过不凭新语法自动等同于完整讲完。

原 BGE INT8、未改权重，使用实际 Java 推荐路径。新增四条开发需求在前后各实际推理，原十二条需求在修改后实际推理，共 20 次模型请求。
