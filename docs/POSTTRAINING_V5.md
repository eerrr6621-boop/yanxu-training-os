# V5 固定预算离线后训练

本实验只新增离线候选模型，不自动替换生产模型或更改生产模型白名单。
训练结果与新的需求/授课事件处理管线验收分开记录；规则修复不计作训练效果。

## 预先固定的设计

父模型为实际完成的 V4 checkpoint，权重 SHA-256：
`3059a19e20ea29b94394f855f0b11ed9d0441e570515cc36658ba3e4653dfeb1`。
逐字段保留其 144 条训练行；新增 12 个人工合成银行/企业培训事实族，
每族 4 个同义需求，共 192 表述 / 48 独立事实族。变形不是独立新事实。
不导入旧 dev、测试集或真人简历；新封存 32 题仅核对 opaque seal 文件哈希，
不读取清单内容、输入或标签。

新增事实区分本人独立完成教学、学员参训、仅做资料或会务、他人授课、未来计划，
并区分课堂模拟材料与整段虚构履历。正负例都包含材料和工作事实。
新 12 族按实际 tokenizer 长度，正例最短 / 中等 / 最长各 4 族（表述各 16 条），
不裁切事实、不增加无关 padding。旧 144 行已有的长度与措辞偏差原样保留，
不声称长度平衡就能消除所有捷径。

固定 CPU 单线程，仅训练 `encoder.layer.3.`；学习率 `3e-6`，
retention 权重 10，梯度累积 4，2 轮 / 96 次更新，种子 20260911，
最终一步 checkpoint，不试超参、不根据测试择优。其余参数、实际训练依赖、
父模型、数据和运行时均在训练前冻结；每次梯度要求有限且非零，
训练后逐张量确认其他层不变。

## 验证范围

新增 12 项纯测试覆盖旧行完整保留、事实族隔离、同族变形共享事实、
token 长度、参数预算和诚实导出身份。它们是开发回归，不是盲测，也不能替代事实人工审查。
导出将校验 ONNX 图、有限且归一化的 512 维输出以及 FP32 与原 checkpoint 的数值一致性；
这些也不是业务匹配准确率。

## 独立封存题的聚合结论

新 32 题由独立执行步骤完成唯一一次 V5 INT8 验收；训练执行者直到全部完成后
仅获准核对聚合数字，没有读取题文、标签或逐题结果，没有据此调参或择优。
其中 16 题有冻结正例。原始向量第一位命中为基模 1 / 16、V4 3 / 16、V5 4 / 16，
V5 的 worker 第一位命中仍为 5 / 16，但最终正例准入为 0 / 16，worker 错误 2 题。
因此不能把原始向量数字的小幅变化称为最终推荐收益，也不能用历史回归 6 / 7
替代对新题失败的报告。独立验收报告的事件来源范围（scope）覆盖计数为 0 / 128；
这是该协议字段的计数，不是全篇简历完整性或资格真实性认证。

结论：已完成训练和可验证导出，尚未获得最终推荐改进证据。
