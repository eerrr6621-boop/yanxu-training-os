# 本地语义辅助：实现与验收状态

日期：2026-09-07。**本页下方为 v4 历史工程验证，不是当前 v5 的验收结论。** 最新真实简历、就近规则与发布门禁见[灰度验证报告](NEARBY_GRAY_VALIDATION.md)：v5 无模型回归通过，但真实模型业务回归未通过，仍未发布生产或同步 GitHub。公共更新记录没有把本轮标为已上线。

**后续挑战评测发现业务缺陷，暂不建议上线自动语义排序。** 工程连通测试通过不等于选师准确；16 组困难构造样本中，现有组合首选命中 10 组，另有否定、地名和规则召回问题。详见 [第二轮诊断报告](SEMANTIC_CHALLENGE_REVIEW.md)。下方保留此前工程验收的原始口径。

## v4 当时已执行（历史记录）

- Java 17 编译及完整隔离回归：52 项基础 API、137 项业务完整性与安全、74 项师资产品测试全部通过。
- 新增 278 项 Java 语义契约/排序/时间边界断言、9 项 Python 分段与期限检查、17 项前端安全输出断言通过；既有 431 项调度/历史迁移、159 项离线天气及其他前端回归通过。
- 用真实 BGE-small INT8 worker 连接 Java，再运行整套师资 API：77 项通过（包含 3 项必须实际启用模型才能通过的断言）。测试使用构造简历、随机本机 token 和独立一次性数据库；没有连接正式业务库。
- 实际模型测试覆盖鉴权、同请求缓存一致、同讲师人工修改后旧证据失效、否定资料不返回正向证据、容量与无效编号边界。失败返回原规则的路径另用可控假 worker 验证。
- FP32 / INT8 各在独立进程跑 12 组构造案例，两者均选中预设首选。INT8 权重约 57.2 MB，本轮 Darwin arm64 进程峰值约 196 MiB，FP32 约 316 MiB；不是生产 Linux 的容量或延迟保证。
- 原始构造评测：[INT8](../semantic/reports/smoke-int8.json)、[FP32](../semantic/reports/smoke-fp32.json)，包含模型与案例散列。导出的实际模型和源文件保留在被 Git 忽略的 `semantic/model/`，未作为网页资源。
