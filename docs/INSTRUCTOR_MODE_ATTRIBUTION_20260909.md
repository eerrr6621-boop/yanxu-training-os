# 讲师授课形式归属修复（2026-09-09）

本轮是本地证据规则修复，不是后训练、封存验收、全国交通补齐或生产发布。未修改评分阈值、交通顺序、讲师真实资料或模型权重。

## 实际发现与修改

原非结构化路径用关键词判断授课形式，并用整条记录中出现的相反形式作否决；结构化路径只检查“授课形式”字段是否包含关键词。因此“学员线下练习”会被当成讲师面授，“讲师面授、学员线上交作业”又会被整段误拦。

新增 `InstructorMode`，同时供字段和旧文本特征检查、同事件联合条件使用：

- 形式须来自明确讲师授课行为，或当前课程内的授课形式声明。
- 明确学员练习、提交作业等活动不提供讲师授课形式，也不否决其已声明的形式。
- 无法归属的形式、教师自身线上/线下矛盾、计划/转述/辅助角色等继续待核。
- 引号中的课程名、示例字样不能提供形式；不完整引号不推断。
- 不创建个人身份、完成经历或课程关联；仍经过原课程与同事件条件。来源记录和审计定位不被匹配用的遮罩改写。

这是有限语法支持，不声称可理解任意中文句子或确认实际履历真实性。
