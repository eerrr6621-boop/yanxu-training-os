# 城市交通参考与维护原则

维护记录：2026-09-07。本文记录逻辑边界，不代表当天完成全国交通核查。

## 用途与范围

城市交通参考用于投标前师资初选，与讲师库、分行名单及具体授课日期相互独立。地区目录会遍历当前已收录城市；目录覆盖完整不等于每条交通路线均已核实。未核查、缺返程、资料过期和只有慢车样本的城市关系保持“待核实”，不得表述为不通车或已超出范围。

铁路两向参考均须严格小于 240 分钟；铁路范围有完整依据、确实未满足条件后，才比较双向均严格小于 180 分钟的直飞参考。单个慢班次不能证明不存在更快班次，不用直线距离或假定速度补算时间。

同城及符合铁路范围的老师统一比较匹配分，同分按讲师等级排序，末位同分全部保留；航空仅作铁路候选不足时的后备。未知地区或交通不能通过高匹配分、较高等级或凑足三人绕过门禁。

## 本轮边界修复

- 线下启用就近偏好、但授课城市未收录或未确定时，候选保持待核实，不会自动切换为不限地区。
- 明确的 `eligibility=unknown` 会否决旧 `rail_time_reference` 展示状态，防止显示字段绕过准入结论。
- 目录的 `reference_checked_on` 来自响应内资料的实际 `observed_on`；目录生成时间单独使用 `catalog_generated_on`，不以打开页面当天冒充资料核查时间。目录日期不代表所有方向同日核查，各方向仍以自身日期为准。
- 过期铁路样本保留原始来源、时刻及核查日期，放在 `historical_reference` 中供复核，明确 `eligibility=unknown`。原有 30 天有效性边界未被延长，历史参考不会自动进入候选池。

## 参考不是实际行程

站到站时刻及城市优先级不保证某个授课日开行、有票、讲师有空或能按时到场。市内接驳、候乘、值机安检以及实际出发地仍需确认。系统保留 `transport_verified=false`、`travel_date_verified=false` 等状态；没有查询服务时不生成班次、票价或虚构分钟数。

## 研究资料的使用权限

存在 `research_only=true`、`business_import_allowed=false` 或 `usage_authorized=false` 的显式限制时，资料不得用于自动业务推荐。门禁覆盖铁路文件/记录/样本、矩阵内嵌铁路记录、航空及完整范围核查和旧版交通参考入口。

历史兼容数据没有新增授权字段时，不因字段缺失而立即失效；这只是兼容策略，**不是对其来源授权的认定**。新来源必须先明确其商用、保存、派生城市参考及对外展示权限。可购买接口不等于获得公开原始数据或派生矩阵的许可，不应将研究专用数据提交公开仓库。

2026-09-08 检查发现，最初本地 `config/rail-timetable.json` 仍缺少明确的使用范围标记。现已将该研究底稿标记为 `research_only=true`、`business_import_allowed=false`、`usage_authorized=false`，保留所有原始记录但停止业务读取，并加入 Git 忽略。不得因兼容旧格式而把这批已知授权未确认的材料视为已授权；它未随本次上传修复发布到生产。

## 长期复用与更新

2026-09-08 补充：用户要求的是维护方完成一轮公开搜集后复用**城市间交通参考**，不是每次推荐实时查票。来源搜集继续进行，不要求用户先交接口文档或时刻表。使用近期公开城市摘要时走独立的 `CityPlanningReference` 层，明确标为初筛参考，并保留约数和双向差异；与下面严格时刻证据的有效期、字段及准入结论分开，不互相冒充。该层比较来源参考值本身，不额外加 30 分钟缩减用户的四小时范围。

本轮已实现独立的“已审核城市交通参考”层，与原始时刻证据分开保存，包含版本、来源、双向依据、实际研究日期、审核状态和适用范围。其代码与合成测试已完成，默认空库；没有将历史研究材料自动标记为已授权或已审核。详见 [参考库结构与维护](CITY_TRAVEL_REFERENCE_SCHEMA.md)。

不能靠刷新页面、重新导入旧文件、更新观察日期或把有效期改成永久来刷新证据。新参考层默认审核后90天复核，最长180天；这是维护政策，并非时间精度保证。原研究资料长期保留追溯，自动准入仍需有效审核；临界、冲突、撤销和缺失资料保持待核实。参考层与具体出行日校验分离。地区扩容时，新城市和新方向默认待核实，禁止宣称全国路线已经全部完成。

## 合成回归

`scripts/TransportReferencePolicyTest.java` 已接入 `scripts/check.sh`。测试覆盖双向、严格边界、未知、历史保留、显式权限拒绝、目录扩容及匹配分/等级顺序，共 50 项检查。

该测试在临时目录创建虚构来源与时刻，主动隔离真实铁路、矩阵、旧版参考及机构文件；没有网络请求、真实讲师录入或生产数据写入。地区扩容仅修改独立测试进程内的字典并在结束时恢复，不生成真实交通数据。
