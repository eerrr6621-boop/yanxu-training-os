## 本轮改动

- 普通推荐不再展示查询日、乘车日期、未提供发布日期、复核到期等采集细节。显示“高铁参考时长”和站点范围；折叠依据保留“资料更新于”、来源和参考用途说明。旧单趟铁路参考也隐藏样本车次与起止钟点，避免误读为已安排的行程。
- 后台原始日期、期限及来源校验没有删除或放宽；前端渲染不修改数据。日期用于溯源维护，不是需要用户选择的出行日期。
- 新增 `PublicUiPopupTable`，支持普通12306查询页五列弹窗：站序、站名、到站时间、出发时间、停留时间。与已有六列表格式独立。
- 新格式仍需通过既有哈希、两名独立读者及原页读事件、来源使用限制、城市范围和日期校验。本轮没有补造真实第二读者记录。

## 计算和范围

只用同一显示列车上游发车至下游到站相减，不多算出发站停留时间。列角色、站序、始终点、停留分钟、查询和显示列车、锚点时钟及历时必须一致；原始缺行不补造。

只接受明确“当日到达”查询区间内的片段。区间外即使时钟递增也不能推断同日，不猜跨日、换乘或反向时长。每向必须严格小于240分钟；某个样本超时、未知或过期都不是完整铁路排除证据，不能因此启用航空。
