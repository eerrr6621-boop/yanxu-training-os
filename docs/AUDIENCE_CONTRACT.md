# 有界受众类型契约

本轮只修复需求与授课事件的受众入口，不改变模型权重、课程词表、证据角色、准入阈值或生产数据。`AudienceContract` 的结果是原文条件支持，不是讲师资质认证，也不是同一批实际人员的身份核验。

## 契约与接入

`audience_contract_v1` 同时保留完整受众值、分组、批次修饰、已支持的身份关系、其他不透明字面限定及解析问题。每个分组和组成部分都有可核对的连续原文范围；范围单位是 Unicode code point，相对于 `normalized_audience_value`，不是原始文档或用户整个需求的偏移。外层已有的需求来源及教学事件字段范围继续保留，不能混用两类坐标。

需求的引导式受众字段、明确“必须面向…”入口、课程回指已绑定的受众条件统一调用 `audienceTerms`。它保留原来的 `List<String>` 接口，但不再生成多串可任选其一的替代需求；唯一序列值仍是完整输入，类型比较信息单独承载。

结构化证据必须从同一个可用课程事件的 `audience` 字段支持对象条件。旧自由文本路径只对已经限定到该课程的对象字段使用本契约；其他叙述保留原有整句字面与角色检查，不从整份简历拼接岗位、机构和身份。比较记录明确标注 `comparison_purpose=audience_type_not_same_individuals`、`verified=false`。

## 本轮支持的三个结构

- “新一批／这批／本批 X”中的批次修饰不会变成“新入职”。类型比较仍须证明 X 内全部岗位、机构与限定。
- “新入职的 X”与“刚入职的 X”共享有界 `new_hire` 身份；资深、实习、新一批不等于新入职。具体年资、数值或其他修饰不会被删掉。
- “P 实习 Q”与“[刚]到 P 实习的 Q”可对齐同一个机构字面值 P、实习身份和岗位字面值 Q。P、Q 不依赖行业词表，必须在同一组源受众中同时出现。源有“刚到”不证明刚入职；需求明确要求刚到时，普通实习描述也不够。

多群体逐组核对，不能从甲群体借机构、从乙群体借岗位或资历。未知限定保留为不透明字面值；缺少或不同则待核，不通过近似字符串或词袋相似度补全。否定、排除、未闭合括号与未承载嵌套字段不会自动通过。

明确“同一批／同一组／原班／指定名单”的人员身份条件持续待核，即使源和需求用了相同词句也不能仅凭类型相等认定同一批人。没有名册或群体身份 ID，本接口不能解决隐含“这些／这批人员”的全部指称语义；本轮没有宣称支持一般人群身份回指。

## 受众与课堂活动分开

已有“老年学员”“行政人员”“零基础教学”特征在结构化路径读取同一事件的受众，不再落到 `learner_activity`。仅有活动讨论老年群体、其他课程的受众、明确否定属性，都不能补齐本课程受众。零基础要求只采用既有明确受众证据词，不靠普通练习推断。角色演练、练习完成、逐项点评等真正课堂活动仍读取活动字段。

## 验证与边界

新增纯合成 `AudienceContractTest`：416 个断言。原已公开的 12 组诊断原文与预期未改，4 个适配正例与 8 个不足反例在完整引导字段→Coverage 路径均符合预期；旧版本仅 1/4 正例准入，本轮 4/4，8 个反例均保持不准入。这是固定开发回归，不是新盲测或总体业务准确率。

本轮 24 组相关 Java 测试共 3413 个断言通过；Python 132 项中 131 项通过、1 项原有跳过。另保留三领域 Java→worker→Java 字面范围协议检查，每域截断、否认、他人主体、另一课程四类变造均拒绝。执行前后涉及需求、事件、证据与 worker 的源哈希一致。

未在本轮执行模型推理、真实 19 份简历复测、线上写入或部署。业务岗位同义词（例如不同岗位称呼是否等价）、任意中文复杂修饰、真实同班身份和资格真实性仍未解决；实际业务改善须在新的完整管线冻结后另外重放，不能由这 12 组回归替代。
