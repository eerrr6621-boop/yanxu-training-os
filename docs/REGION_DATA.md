# 省市名称候选字典

本字典用于讲师常驻地、授课地的名称建议、已知省市归属校验及同城识别。它是本地静态候选数据，不是实时权威行政名录，也不是交通数据服务。

## 实际转换

后端 `src/com/training/RegionDirectory.java` 的 `CITIES` 与前端 `web/regions.js` 的 `YX_REGION_CITIES` 均保存“规范省名 → 规范城市／地区名称集合”。运行时使用名称及其父级归属，不保留上游区划代码，也不在线请求上游文件。

1. 大陆部分来自上游 31 个省级条目。省级名称转换为应用使用的简称，例如“吉林省 → 吉林”“广西壮族自治区 → 广西”。
2. 北京、天津、上海、重庆聚合为各自一个城市项；不把上游直辖市 `children` 中的区县分别作为城市。例如“重庆 → 重庆”。
3. 其余省份保留上游**所有直接子项（immediate children）**，不递归展开下级，也不只筛选名称以“市”结尾的条目。因此同时包括地级市、地区、自治州、盟、省直辖县级市、直属县／自治县及林区。这些是业务中的“城市／地区”候选，不表示它们均为同一行政层级。
4. 城市名称仅去掉末尾的“市”用于规范匹配；“地区／自治州／盟／县／自治县／林区”等后缀保留。例如“吉林市 → 吉林”，但“延边朝鲜族自治州”“定安县”“神农架林区”保持原名。
5. 香港、澳门不来自该大陆 JSON，分别人工补充为“香港 → 香港”“澳门 → 澳门”单城市项。台湾、境外保留明确的省份／地区选项，但当前未附城市候选字典，城市名称可人工填写。

## 匹配与使用边界

`src/com/training/DispatchPreference.java` 负责输入规范化与判断：省市文本执行 Unicode NFKC 规范化并移除空白；省名去除受支持的末尾行政后缀，城市名仅去除末尾“市”。

- 归属按规范化后的**省名与城市名组合**判断，不把城市名与省名简单互斥。因此“吉林省／吉林市”规范为“吉林／吉林”，是字典内的合法组合。
- 若名称已在字典中，但只属于其他省份，则提示省市不一致；直辖市和香港、澳门只接受对应的单城市名称，不接受区县替代。
- 未收录名称在通过基础格式校验、且未触发已知归属矛盾时可人工填写；不自动猜测归属、不做模糊别名替换。未收录不等于现实中不存在。
- 常驻地与授课地都被当前字典识别，且省市组合一致，才会标记同城。未知名称即使双方填成同样文字，也不参与同城识别或同城优先，需核对名称或更新字典。
- 同城优先还需已启用该偏好且授课方式为线下；线上授课不按地区排序。省市归属不能证明通勤便利、讲师有空或差旅费用为零。
- 本字典**没有坐标、直线距离、交通距离、路线、班次、耗时或票价**。异地不按“同省”推断更近；真实交通及总差旅需另行核实。

## 维护约定

更新名称或归属前应人工核对可信来源，同时更新前后端两份字典及本说明中的来源版本。不要通过不受控的后缀删除、模糊匹配或过时别名自动推定归属。新增城市及历史名称迁移应保留可追溯依据；上游已停更，固定版本仅提供当前候选基线。
