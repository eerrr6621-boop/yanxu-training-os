# 混合来源范围：检索并集，证明分账

本阶段解决不完整简历已有 `server_teaching_event_scopes` 时，独立专业列表／课程栏目被覆盖、不再参与检索的问题。它是来源处理协议修复，不是后训练效果。本阶段不修改需求语法、教学事件解析器、模型、数据库或已封存评估资料。

## 合同

仅当事件范围与独立专业范围都有效且非空，worker 返回 `mixed_source_scopes_v1`。条目沿用现有 kind、event_id、标题及 Unicode code-point 坐标；没有虚构标题、改写引文或模型生成的授课事实。

`evidence_complete` 仍为 false；`scoped_evidence_complete` 仅承载所用评分范围，不表示整份简历完整、讲师资质认证或最终适配。完整文档仍返回 `document` 和空 scoring_sections；单类范围保留原协议。混合版不能携带未知 kind，旧版不能携带混合种类，重复及变造范围拒绝。

所有条目一起最多64个；保留原512单元上限，并另外检查实际合并后评分单元总数，超限明确失败，不静默截断。相同原文位置、仅句末标点范围不同的同一事件只嵌入一次，引用仍是未重写的完整原文单元。相同文字出现在不同位置时保留各自来源，不能据此累计授课次数。

## Java 验证与消费

Java 将混合条目按原 kind 分给既有来源验证器，从完整源独立重算事件及专业范围。每个返回 evidence_unit 的文本、code-point 起止、context 和标题都需验证；整单元必须落在一个已核验范围内，不能跨空隙拼引文。

空标题只可匹配实际无标题列表范围；课程名在栏目标题之前的既有 `course_catalog_entry_v2`，按实际范围中的 heading 坐标核验，不能假设所有标题都在引文前。另一个真实栏目标题也不能冒用。

混合消费先从完整规范化简历提取原 records/events，再按已核验范围筛选；不会对拼接或掩码文本重新绑定主体、课程、对象或完成状态。`maskedSource` 不向混合调用者提供合成简历。原单类消费分支未改。

同一事件ID只出现在事件集合一次。原叙述记录可保留尚未结构化的同段形式／活动证据，但不会由记录数量计算授课场次，也不能将不同课程的对象和次数拼成一次符合条件的教学。

专业目录有 content-only 上限：如果旧分类器因更早的“授课风采”标题把目录误标成历史，本视图保留 `source_record_role` 供审计，同时将实际证明能力限制为内容。豁免须在同一原文记录中通过既有本人教学与独立历史判定，不能只凭“主讲课程”标题或没有完成状态的“本人主讲”借得历史。源事实生成器本身和单类路径不受这项局部上限修改。

实际发生的角色上限同时输出在候选的 `scoped_evidence_role_limits` 中，包含原角色、有效角色、来源记录ID和明确标记单位的偏移，不增加简历原文或个人信息。离线候选审计可直接保留该事实，不需重新计算业务判定。

## 验证范围与边界

固定合成对偶覆盖三个领域：目录与事件共同检索、事件去重、目录不能补本人履历、不同课程对象／次数不互借、正确同事件仍能支持、全文否认、Unicode坐标及协议变造。它们是开发回归，不是新盲测或真实客户总体准确率。

此前专门记录 EVENT 覆盖 profile 的测试保留原 fixture；该单项预期经明确确认改为检查两类并存、mixed版本及全文仍不完整。旧快照、旧结果与旧行为记录保留，其他旧安全测试标签未放宽。

未解决范围包括未知课程语义、来源真实性、重复叙述是否代表不同实际场次、超限材料自动拆分，以及其他单类路径历史遗留的角色解释问题。混合范围不会把这些问题解释为模型失败或自动放行。独立协议回归和源码指纹保存在本次私有验收目录，未部署。

本轮最终独立副本回归：27 组 Java 共3888个断言通过（新混合范围198个）；Python150项中149通过、1项原有跳过。三领域实际 Java 生成范围→worker 处理→Java 重验全部通过，每域12类 scope 变造和跨范围 unit 均拒绝，另每域2个后置标题目录引文通过。纯协议 stub 不代表模型推理；旧probe18项自测与另一个代理负责的混合probe专项回归分别计数，不混称全量上线验收。

开发期已保留：后置标题旧校验误拒、真实 headingless unit 使用 null 而非空串引起的误拒，以及一次私有验证脚本变量覆盖造成的收尾失败。最终版本只允许 null／空串对应已核验的实际无标题范围，非空栏目不能省略或借用标题。旧输出未覆盖；没有为了通过验收修改历史业务标签。
