# 配对证据模型：固定 20 轮开发训练

本轮实际完成 20 个 epoch、1120 次参数更新。结论是：相对排序和部分召回改善，但仍不能作为“证据充分”的自动准入判断，未采用、未量化、未部署。不再按这份开发集的分数自动追加训练轮次。

## 与 3 轮实验的严格区别

从相同原始 BGE-small-zh-v1.5、同随机种子重新开始；数据、56/12/12 整族划分、学习率、损失、后两层和评分头完全不变，仅增加训练时长。没有拿上次权重配新优化器冒称连续恢复，也没有择优挑选中间轮次。新增逐轮日志与最终训练集诊断不反馈梯度。

本轮是看过前一轮开发指标后的开发实验，没有运行旧 16 题族留出题，也不声称本轮做了新独立评测。所有用户简历仍未进入梯度。

20 轮的训练集相对 Top1 为 56 / 56，但在校准阈值下仍有 2 / 112 个训练负例误放行。这说明跨需求的绝对分数并未稳定分离，不只是没有记住训练题。内部集仍有 PD06、PD30 两个族排序错误，校准 PD76 的负例决定阈值；原题、标签和对应失败分数均保留，未据此改标签。

预定开发筛查要求内部误放行 0、正例过阈值至少 8 / 12、Top1 至少 10 / 12；本轮只满足最后一项，所以不进入自动采用流程。未来若改为“只在已满足规则条件的老师之间辅助排序”，属于不同用途，也必须另做端到端安全与真实简历收益验证，不能把本轮失败包装成通过。
