# 无标题开头专业列表：有界来源范围

这是独立于已复制 `audience-final` 管线的下一阶段源码修复。没有修改该冻结快照、模型、需求解析、教学事件类、旧验收标签或旧报告。本轮没有运行 embedding，也没有读取新 40 题来设计或调整代码。

## 修复的层次

原逻辑可以提取开头的勾选式能力列表。但如果简历另一段包含参训、身份未确认等内容，worker 会转入独立范围评分；没有栏目标题的开头列表不在这些范围内，已提取的专业信息因此不再参与检索。

本轮增加 `leading_profile_list_v1`，不是把所有已提取单元放行：只接受开头连续 2–12 个同标记的短名词条目，整体不超过 220 个 Unicode code points，每条内容不超过 80，必须有已识别的下一栏目闭合。仅有一个条目、混标记、中间空行后继续拼条目、未承载正文、缺闭合边界、过长列表均不靠截断补救。个人专属元数据可位于列表之前，但不进入正向引文；未知介绍文字不能被跳过。

来源范围保留整个连续列表。`heading` 是空字符串，标题起止相同，绝不伪造“擅长领域”等栏目。`context_start/context_end` 指向完整规范化简历，而不是裁出的正向子句。全文角色、否认、来源归属与未消解列表指代仍需核查；不明归属继续待核。

引用检查只忽略已识别的完整栏目标题行，例如独立一行的“课程列表”。“上述列表不是本人方向”或“课程列表仅为团队产品”仍是正文，不会作为标题删除；其他全文主体、角色、否认及资格检查继续接收完整原文，来源坐标不变。

能力名词中的“资格／认证”可以作为不透明内容，不代表讲师持有相应证书；“取得／获得／持有”等断言不能混作普通名词列表。判别个人与计划动作采用有界语法位置，避免把“自我…”中的“我”、 “拟合…”中的“拟”直接当作主体或未来授课。

## 协议与准入

含新范围的响应使用 `independent_profiles_v1`。旧 `independent_sections_v1`、`independent_facts_v2` 不能声明新 kind；新版本也不能在没有新 kind 时随意使用。Java 用完整源独立重算列表范围和上下文，逐项核对；不能仅相信 worker 返回的坐标或标签。

实际范围评分保留 `evidence_complete=false`，仅声明所评分范围有效。原来完整的文档仍返回 `scoring_scope=document` 和空的 `scoring_sections`，不会被新增 override 错标成范围评分。独立静态审查发现并修复了该完整路径的括号/元数据问题，未据此声称业务误准入改善。

本改动不创建教学事件，不更改 ProfessionalEvidence 角色，也不新增课程名词理解。专业能力自述仍不能满足“本人已完成授课”、受众、形式、次数或资质认证等独立条件。范围恢复不等于最终准入。

## 已执行验证

- 新 `LeadingProfileScopeTest`：114 个固定断言通过。
- 25 组 Java 回归共 3527 个断言通过；142 项 Python 中 141 项通过、1 项原有跳过。
- 三领域 Java/Python 范围逐字段一致；每域 9 类变造拒绝，包括截断、缩短上下文、伪造标题、偏移单位、旧版本、全文否认、角色与未知前缀。
- 对此前已暴露的单份 F11，仅重放原解析 JSON 的纯证据链：目标专业标签从未参与范围评分恢复为参与，评分单元 4→5，已有内容条件恢复 `source_supported`。受众条件仍缺证，最终仍不准入。没有重跑模型、重新解析 PPTX 或把旧主题相关标签改成完整适配。

首次开发测试错误地把任意未知专业名词列表的恢复等同于最终准入。原失败源码与输出已保留；经明确确认，测试收窄为同一未知例的连续引文恢复、范围校验和不升级授课历史，没有替换成熟领域词或修改旧验收标签掩盖限制。

前一已验证阶段还会把完整“课程列表”标题误当未承载引用。原源码、报告与结果已保留；本修订仅限上述完整标题行的引用检查，新增三领域标题正例与归属否认负例后独立重新编译、回归及冻结，未覆盖先前记录。

## 明确保留的限制

1. 既有 `server_teaching_event_scopes` 仍优先于专业列表。在不完整简历已有事件范围时，worker 仍用事件范围，专业列表可能再次不参与评分。新增测试明确记录此现状，不伪装成已修复。未来若设计异类范围合集，需要逐类独立重验，并防跨课受众拼接及同一事件重复计数。
2. 引用/归属检查仍较保守；除完整已知标题外，其他未消解正文指代不自动跳过。不宣称覆盖所有简历排版。
3. 任意专业名词、复杂未标题段落和来源真实性不在本步解决范围。不能把这次来源范围修复解释为后训练收益、整体推荐准确率或已上线能力。
