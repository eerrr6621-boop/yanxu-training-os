# 逐项需求条件修复（本地规则验证）

日期：2026-09-07。未部署、未训练；未修改任何既有训练或封存评估标签。

## 本次改变

- 显式主题即使不在小词表中也单列，不再让另一个分句的文字命中代表完整主题。
- “需要面向”与其他明确对象条件一起核对；面对面/线下和远程形式分别核对，混合或未说明不能推定符合。
- “已完成两次”等既有课次要求进入次数核对。每场练习、反馈及授课时长单列；累计时长、课时数、一次环节不能替代逐场要求。
- 多课次的次数、形式、对象与逐场环节须绑定同一组本人已完成教学证据。不同来源行的无关课次不能互相补齐；多个主题的逐场条件分别核对。
- 经营数据分析从成本预算中独立出来。同一讲师完整覆盖的条件只在该候选人全部独立模块都有资料支持时通过，不跨候选合并。
- 明确的助教/参训/资格证/筹备不等于本人教学，可由相应本人经历回应。仅当原需求完整角色列表已核对，才接受 worker 逗号切分出的对应否定后缀；其他未知排除仍待核。
- 已要求的授课资格真实性保留独立待核项，有资料声明时保留其证据，不冒充第三方资格认证。

## 验证与标签边界

新增 `RequirementAtomicTest` 使用跨焊接、园艺、仓储等独立编写的正反例，包括缺对象、错形式、次数不足、逐场环节缺失、未知新主题借时长、分钟与未定义课时混淆、单人四模块与不完整拼接。

经主任务明确授权，旧 `holdout_care_02` 的四个固定样本另作复用诊断：正例满足全部条件；错误对象、远程形式、第二次缺环节三个负例均不应准入。这不是新盲测，不反向修改其标签，也不将其效果计作现实业务准确率。

`EvidenceContextTest` 有一项明确的单元预期调整：原查询要求面向“国企中高层管理者”，原资料只有国企领导力与战略管理主题，缺授课对象证据。原查询和资料保持不动，将此前的准入断言改为待核，并新增有明确受众证据的防注入正例。原先通过属于漏解析对象的缺陷；此次不是修改基准题/训练标签，不用这项变化制造准确率提升。

## 仍然保守的范围

这不是通用自然语言逻辑证明器。未支持的量词、逐模块复杂配额、相互矛盾的形式、资格真实性及无法绑定到相同已完成事件集合的事实继续待核。不会从模型分数、岗位经验、多个老师、其他课程或语义相似的资格名称补出缺失事实。原始来源仍由证据层提供，规则只引用连续原文，不拼造证据句。
