# 主动授课叙述：对象、完成范围和形式修复

2026-09-09。源证据解析与业务约束修复，不是新一轮模型训练、盲测准确率或上线公告。

## 已修复

上一次源字段提示训练在PD08把在线录屏误当作满足现场面授，诊断发现提示中的对象被提取成“账号管理员完整”，且未提取形式。本轮不改变模型分数或阈值，先处理这些输入错误。

- **授课动作修饰语与对象分离。** “我已给账号管理员完整讲授……”中的对象现为“账号管理员”。支持完整与独立、亲自等有界组合，保存原文字段范围；不完整、未必完整、基本完整等限定仍待核，不把它们删除后当成肯定事实。
- **区分过去讲过与全课完成。** 明确过去的“完整讲授”可以标为全课完成；只是“讲过”保留为过去授课，不自动满足全课完成条件。“完整”形容词本身不创造过去经历。已有明确完成关系不会被同课程的后续普通提及抹掉。
- **同课程的形式续句。** “采用现场面授”“采用在线录屏”等原文绑定到当前事件；录屏、录播是远程，不是现场或直播。形式句不能自己创造课程、主讲人或已完成事实，混合形式、未来计划、他人和跨课程条件继续受限。末尾形式字段也必须处于完整事件的原文范围内。
- **省略主语边界。** 前句在说学员活动时，后句仅写“采用/使用……”不能自动认定是在说教师形式；明确“授课形式为……”的课程标签另作处理。这是第一版通过后补查出的保护，最终版重新执行了回归与模型对照。

本轮改变的业务源码仅为`InstructorMode.java`、`NarrativeTeachingEvents.java`，另新增`ActiveTeachingFieldsTest.java`并加入完整检查脚本。没有添加领域答案词表、改变历史相关标签或启用未通过验收的模型。
