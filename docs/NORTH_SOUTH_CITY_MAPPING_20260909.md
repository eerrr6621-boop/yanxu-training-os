# 南北向车站城市归属整理

2026-09-09，内部研究记录；不是上线公告，也不代表全国交通核验完成。

## 本批结果

已把具名郑州东、武汉、咸宁北、岳阳东、长沙南五站整理到对应城市。对前一批六张12306停靠表重算，688条有明确同日查询区间的样本中，42条两端具备本批城市映射，646条尚未映射。日期依据不足的103条区间外组合仍隔离，未纳入计数。

五城形成10组双向、每向均存在小于240分钟样本的研究组合；其中郑州—武汉与当前可用40组重叠，另外9组尚未准入。**可用数仍是40，不能写成49或50。** 武汉—长沙虽有本次新样本，也不自动恢复原已撤回的参考记录。

郑州—长沙保留的样本同时有超过240分钟与低于240分钟的列车，两个方向各存在达标样本。采集到的一趟慢车不应否定其他已采集的达标列车；反之，样本中没找到达标列车也不是完整铁路排除证据，不能自动启用航空。

- 咸宁北：[咸宁市自然资源和规划局正式建议答复](https://zrzyhghj.xianning.gov.cn/xxgk/fdzdgknr/zdgknr/jytabl/2021jyta/202110/t20211012_2409055.shtml)，仅作具名站点行政背景，不采用2021年的接驳和工程状态为今天的旅时依据。
- 武汉：[铁路武汉站实体](https://www.wikidata.org/wiki/Q584376) → [洪山区](https://www.wikidata.org/wiki/Q1337284) → [武汉](https://www.wikidata.org/wiki/Q11746)的CC0结构化行政链；区分同名地铁站，未合并汉口/武昌站。
- 长沙南：[铁路站实体](https://www.wikidata.org/wiki/Q986410)明确的长沙城市描述与[长沙市实体](https://www.wikidata.org/wiki/Q174091)当前湖南归属。保留搜索请求Q28804526实际返回Q174091的重定向记录；街道行政链未核齐，不声称已核实。

上述政府来源只摘录最小事实，不复制文章或宣称整站开放许可；Wikidata是社区维护的结构化地理资料，不是政府准确性认证。另发现的武汉生态环境局作品和湖南英文站目录有使用限制，未导入本包；石家庄采购页403拒绝后停止该来源，不绕过。

本批仍只有根任务一个原页读者；算术重算不是第二个来源读者。没有根据坐标计算旅时、镜像返向、估算接驳、保证未来班次、准入航空或修改生产。观察日9月9日和乘车日9月10日始终独立保留，未伪装成旧同日入口可直接接收的资料。
