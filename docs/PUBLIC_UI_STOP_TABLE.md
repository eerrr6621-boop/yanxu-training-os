## 数据与计算

- 仅接受 `https://hzfw.12306.cn/zgzfw/resources/web/skcx.html` 的明确新来源类型与方法；旧城市查询页面、文章来源及旧方法仍走原有校验。
- 六列按页面实际顺序保存：站序、车站、车次、出发时间、到达时间、历时。每个单元格保留自己的原文单元及哈希，不能把另一列中恰好相同的文字绑定进来。
- 以同一表格的上游站**出发时间**到下游站**到达时间**计算。历时列只核对始发基准的一致性，不能把两行历时相减冒充旅时：那样会多算上游停站时间。
- 可保留部分选定行，但站序必须递增、不重复，所有行须匹配同一显示车次。起终点空值与站序、标题相互校验；初版只接收明确“当日到达”，未支持的跨日情况保持未准入。
- 查询车次与实际显示车次分别记录。两者不同并不自动证明别名关系；计算只绑定页面实际显示车次及其同表行。
- 只生成有向站点样本。城市归属需独立核对；返向需另读来源，不镜像分钟数，不拼接不同列车，更不把没有样本当成铁路超时或航空后备证据。

## 站点到城市的复核工作清单

`scripts/PrepareStationCityReview.java` 是离线研究辅助脚本，不被生产服务调用。输入需显式指定文件和SHA，输出只能新建到非公开目录。它重新检查每向样本、严格小于240分钟的边界、统计和重复站点对；城市目录仅提供字面名称建议，绝不据此证明地理位置、主城区范围或第二人复核。

本次实际47站/60组待核组合中，28组两端各有唯一字面名称建议；32组至少一端没有唯一建议，包括汉口、恩施、曲阜东等。没有自动把汉口改写为武汉、把县级城市变成其上级城市，也没有补算接驳或开放航空。工作清单按影响的待核组合数排列站点，仅决定资料复核顺序，不是讲师就近排序。45项合成检查与根任务独立算法重算通过；完整 `check.sh` 尚未运行。

## 接线与边界

已接入原有保护性来源校验、双读一致性、城市范围、日期/过期检查、规划选择及v2展示。没有新增默认启用配置或放宽旧来源权限。来源、两个独立读者和外部约束仍由原有外围校验，解析器及哈希本身不认证读者、不授予复用许可，也不证明城市归属。

具名样本只表示查询当日观察到的站到站用时，不声称最快、典型、门到门或未来班次保证。资料可维护复用，复核期限不会被无来源的重新保存延长。仍按双向各小于240分钟初筛；未知、缺返向、过期或受限资料不触发航空。
