# 课程对象与完整教学动作：有界修复

本修复不训练模型、不修改真实简历、交通数据或旧验收标签。目的在于承载明确的
需求角色，而不是把句子里任何“讲／教”后的字符都当课程主题。

## 承载范围

- 明确的未来教课意图可以只有字面主题，不强制附带受众。例如“我们下次想讲
  竹片含水率记录”可建立课程节点，受众保持缺省，不编造对象或已授课经历。
- 已有唯一课程节点时，有界“老师必须已经自己把这门课教完过”可绑定原课程
  的个人完成要求。缺前文、两个候选课程、未承载的条件仍待核；过去与未来不混用。
- 完整动作与体标记采用不可回退边界。没有宾语的“教完过／教授过／讲完过”
  不再通过正则回退变成“教”加虚构课程“完过／授过”。
- 未引号对象遇到限制从句、排他谓词或数值比较时，整句保留为未承载条件。
  不删掉后半句，只取有利主题；课程名重复“只接受持证人”不能证明讲师持证。

主题、课程引用、条件仍保留原始跨度。无对象声明不会创建受众 span。显式
“这类学员”对前文唯一受众的跨课程回指可以具有实际语义，不能只因跨 course ID
就称为误准入；没有对象回指时，不往历史条件中填入该对象。

## 已验证与失败保留

三类陌生合成主题的固定测试共 163 个断言通过，包括对应已完成事件准入、
助教／计划不准入、未决引用、虚构动作宾语和课程名吞掉条件的对照。
修复前缺少无受众声明、初次孤立编译遗漏 Java 编译期常量消费者、课程后缀截断
指示词的问题均保留原失败日志，没有覆盖成成功记录。

独立审查发现三个新声明将排他条件整句吃进课名的实际误准入：首次 query 和
source 先封存，复测不再按新解析结果重新生成来源。修复后这三例 true→false，
既有阴性仍 false、两个阳性仍 true；六项预定检查通过。另两项软偏好／或选
仅记录观察，不计作通过。输入、预期及旧输出未改。

这只是语法／规则测试，不是新的独立业务准确率。此前已经暴露的 40 题若再次
回放只能称开发回归，新模型是否带来最终推荐改善必须另外评估。

## 尚未解决

未引号自然名词短语中的教学词边界仍可能误解析。例如受众职业词内部含“讲”，
现有惰性匹配可能将受众截短；不能只改成贪婪匹配或用行业名单遮蔽。独立测试
记录该例最终未准入，未将它包装成安全漏洞已修复。软偏好、明确放宽历史条件、
复杂或选和多课程回指也未在本步完成，不能宣称已支持所有自然语言。
