# 中文 NLI 业务证据后训练对照

2026-09-08 实际完成一次本机离线训练。**未通过验收，不上线、不替换当前模型。** 本文不是面向客户的版本发布说明。

## 实际结果

使用相同架构、相同原文、同一整族数据划分，训练前先完成基线评分。内部开发集为 12 组，每组 1 条充分证据与 2 条不充分证据。

| 内部开发集 | 训练前 | 训练后 |
| --- | ---: | ---: |
| 充分证据通过 | 0 / 12 | 4 / 12 |
| 不充分证据误通过 | 0 / 24 | 5 / 24 |
| 充分证据严格排第一 | 2 / 12 | 7 / 12 |
| 通过且严格排第一 | 0 / 12 | 3 / 12 |

各模型独立以其校准集的最大负例分数设阈值，严格大于才通过。校准集训练前/后分别为 TP 0/2、FP 0/0、Top-1 3/8；该集合上的零误放行是阈值构造结果，不代表外部准确率。

预先设定的内部门槛是误放行 0、充分通过至少 8/12、严格 Top-1 至少 10/12。三项均未达到。固定 `P(E) >= 0.70` 的辅助对照，训练前 TP 1、FP 0；训练后 TP 4、FP 5，同样不能接受。排序有改善，但不能称整体业务准确率提高。

## 训练范围与资源

- 起点为 [IDEA-CCNL/Erlangshen-Roberta-110M-NLI](https://huggingface.co/IDEA-CCNL/Erlangshen-Roberta-110M-NLI)，固定 revision `864d25be3ce5e90d9193cb49d9fbd52722cdc6b0`。
- 沿用经复核的 80 组 AI 合成事实族，原 56/12/12 整族划分、原文与标签不变；不将内部开发题称为新盲测。本轮没有用真实讲师简历训练，也没有读取新的封存验收题。
- 原候选全文作为 premise、原客户需求全文作为 hypothesis，没有删去硬约束或截断，最长 260 token。
- 固定 3 epochs、168 次真实参数更新，最后 checkpoint 唯一交付；只训练最后两层编码器和原分类头，共 14,178,051 个参数。34 个张量实际改变，167 个冻结张量未变。
- 标准本地 BERT、FP32、CPU 单线程；`weights_only=True`，无远程代码或不安全反序列化回退。保存的 safetensors 逐参数等于实际评测权重。
- 本机训练 42.19 秒，整段进程 55.19 秒，进程峰值 RSS 1636.20 MiB。它包含梯度和优化器开销，**不是服务器推理常驻内存**。没有在业务服务器训练。

## 结论

保持业务证据核验与语义排序分离。当前失败权重不会因排序提升而获得准入权，也不通过临时降阈值、改标签或多跑几轮包装为成功。真正的上线验收仍需未参与训练的新题、真实简历回放及量化/资源测试。

## 后续只读诊断与一次输入 A/B

内部 5 条误放行中，3 条将同事的课程归到当前候选本人，1 条忽略明确对象限制，1 条缺少同课必需模块。固定分数的最高反例超过全部正例，因此单独提高全局阈值虽然能消除误放行，也会拒绝全部正例；不能这样宣称修复准确率。

已执行唯一预先固定的原文外壳 A/B：候选全文前增加“当前候选讲师的资料原文”，需求全文完整嵌入“当前候选讲师本人能够满足以下业务需求中明确提出的全部条件”。未删改原文或标签，未训练，两模型原始控制复跑均与旧分数完全一致。

| 内部开发集 TP / FP / Top-1 | 原文输入 | 唯一外壳 |
| --- | --- | --- |
| 原 NLI | 0 / 0 / 2 | 0 / 0 / 4 |
| 失败训练权重 | 4 / 5 / 7 | 1 / 0 / 7 |

各条件仍按自己的校准负例上界比较，分母为 12 / 24 / 12。外壳下误放行减少伴随充分通过减少，不能称输入修复成功。固定 `P(E) >= 0.70` 时训练外壳仍误放行 3/24。四条件均未过门槛，没有继续尝试其它模板。

实际总计 288 对，24.21 秒，进程峰值 RSS 1079.39 MiB；包括模型加载和审计，不是线上单次延迟或常驻内存。报告 SHA-256：`e9ef4187632770609e07fc6c679d7176263c63729f757d60b1e5fe80756e4ce7`。

下一步开发目标改为补充事实关系监督：复用已有课程事件和原文跨度，区分本人/同事、可供课/已授课，以及每个模块所属的课程。它不是新增已完成的训练成果。19 份已参与开发的简历可用于本地标注与回归，但不能重新命名为全新盲测；同一讲师及其改写样本不跨训练/验证集合。

## 关系辅助实验：已运行，仍未通过

2026-09-08 下午，在原始 NLI checkpoint 上另外完成一次固定实验；没有续训上一份失败权重。原56个训练族增加168组三态关系题，共504条辅助配对，全部经过语义复核与原文修改回切校验。504条不是504个独立讲师或真实简历，仍只有56个合成事实族。

主业务损失之后累积0.5倍C/N/E关系损失，固定3轮、168次参数更新，每条辅助配对仅使用一次。新增加的独立验收题已于训练前封存，但本轮内部开发门槛失败，未启封其题文或标签进行评分。
