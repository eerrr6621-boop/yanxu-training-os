- 保留连续原文、段落边界、标题范围和来源偏移，后文否定不能被删除后反向变成资历。团队案例、参训、旁听、助教、计划课程、明确他人授课与本人实际主讲区分处理。

- 把需求正向内容与排除条件分开。未可靠核实的硬条件不再被静默忽略；逐项列出缺少依据的要求。
- 对授课年限、时长、次数作显式核对。日历年份、岗位从业年数、范围上限、小数尾数、分数、茶歇/通勤、另一门课的时长不能代替对应的个人教学事实；分钟与小时可明确换算，课时不擅自转换。

- 独立的年龄/性别字段不参与能力比较，也不因其存在而否定其他专业证据。混合在无法可靠分割段落中的个人信息仍保守处理。

这些是预处理、证据规则及协议修复，不是通过后训练让模型学会事实核验。相似度仍只表示文本相关程度，不是讲师能力认证、胜任概率或真实授课记录。
