## 问题与修复边界

原来在“未授课课程”栏目写“本人没有讲授《数字营销》”，会命中全篇否定检查，连另一栏目明确记载的服务礼仪授课也一起屏蔽。修复前的新 Java 用例实际在第一条局部否定检查失败。

现在只对两类明确标题（未授课课程、未讲授课程）下的**完整、具名、第一人称否定句**确认局部范围。句子必须完整匹配，不能含追加声明、跨行内容或未解析指代；遇到其他栏目标题即结束该局部栏目。其他位置的否定和“以上／以下”等跨栏目指代仍保留原拦截。括号内写“以上全部课程”也不被当作具体课程名。

此范围视图仅用于全篇否定／角色限制的判定。原始正文、引用、位置及负面声明不删除、不改写；被否定课程始终不参与正面相似度评分。Java 在限定评分章节前检查原文课程冲突，因此即使独立章节的相似度有分数，也不能据此放过同一需求课程的否定。

这不是对所有自然语言否定的完整解决方案：缺少明确栏目、使用“该课程”或具有复杂关联的句子仍需核对。没有把“能按课程说明匹配”升级为授课事实真实性认证。
