# 南北干线：八个枢纽站的城市归属扩展

2026-09-09。本地研发记录，不是上线或全国覆盖完成公告。

本批在原12站基础上增加北京西、广州南、石家庄、衡阳东、信阳东、保定东、韶关、清远八站的最小城市事实。原六张12306停靠表没有新增或改写；增加的是已有样本能够对应到城市的范围。

## 实际结果

| 指标 | 前批12站 | 本批20站 |
| --- | ---: | ---: |
| 两端均已对应城市的有向样本 | 161 | 448 |
| 仍有车站待对应城市的样本 | 527 | 240 |
| 形成的不同城市组合 | 63 | 174 |
| 至少有一个样本支持各方向的城市组合 | 46 | 114 |
| 两个方向各有小于240分钟样本的城市组合 | 39 | 76 |

**本批新增37组待复核研究候选，不是新增37组已可用路线。** 76组中有2组与原可用40组重叠，另外74组未准入；其中1组与旧撤回历史重叠，不自动恢复撤回记录。正式本地可用仍40组，生产未变。

另外60组仅有单向样本；38组有双向样本，但本批不能证明两向均小于240分钟。两类均不提供“已查无合格高铁”的证明，不据此启用航空。没有镜像生成返程，没有拼接不同列车，没有按直线距离或平均速度补分钟。

## 地理事实及其限制

- 北京西：[北京市政府原页](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202603/t20260311_4554596.html)明确该站在丰台区。页面显示2026-03-11 14:30、来源北京日报。只采用北京城市归属，不复制文章或导入施工、接驳信息。
- 广州南：[铁路站实体](https://www.wikidata.org/wiki/Q1073420)的行政属性指向[石壁街道](https://www.wikidata.org/wiki/Q14328343)，此前实际原页描述明确广东广州。属性无引用，不当作政府核证；石壁页本轮刷新非重试失败后停止，采用此前同日实际读取的2410819353修订事实，不声称刷新成功。
- 石家庄：[铁路站实体](https://www.wikidata.org/wiki/Q987999)指向[桥西区](https://www.wikidata.org/wiki/Q1027301)，后者原页明确河北石家庄。铁路实体混有2012年旧站关闭和在用属性，保留冲突，仅作城市分组，不据此断言当前建筑或运营状态，也不使用同名地铁站。
- 衡阳东、信阳东：分别实际读取[衡阳东原条目](https://en.wikipedia.org/wiki/Hengyang_East_railway_station)与[信阳东原条目](https://en.wikipedia.org/wiki/Xinyang_East_railway_station)，明确湖南衡阳和河南信阳。独立条目的最小城市事实不意味着旧失败的行政父链已经读全。衡阳政府页412及信阳Wikidata非重试失败均保留，未绕过或将搜索摘要算作原页读取。
- 保定东：[原条目](https://en.wikipedia.org/wiki/Baoding_East_railway_station)位置栏和正文明确河北保定；未根据搜索额外填成莲池区，也不延伸到其他县域站。
- 韶关：[原条目](https://en.wikipedia.org/wiki/Shaoguan_railway_station)明确广东韶关的SNQ铁路站，并区分现韶关东站。两站的时刻和位置不混用。
- 清远：[具名铁路实体](https://www.wikidata.org/wiki/Q1305743)描述明确广东清远。未继续补造区乡父链，不使用赛事“清远站”或其他站点的工程名称。

Wikidata结构化字段按页面显示为CC0；Wikipedia正文按页面显示为CC BY-SA 4.0，不把两者混称。私有包只整理最小地理事实并保留出处、作者归属和修订号，没有复制网页全文、图片或地图。许可标签也不是正确性或政府认证。本批保留旧来源失败记录，新增独立事实不会把旧失败改写成成功。

## 验证

- 重新编译当前Java代码及研究工具成功。已有未使用方法警告未冒充错误或额外修复。
- 车站队列45项、城市分组36项合成检查通过。这些检查验证整理逻辑，不代表地理正确率。
- 另一Node实现从原96行到发时钟重算688条具备日期锚点的区间，103条锚点外区间继续隔离。读取/查询日2026-09-09与样本乘车日2026-09-10分别保留。
- 逐项核对原始行摘要、表和行索引、两向时长、城市映射引用、分组车站集合、未映射队列数量、阈值、旧可用/撤回集合的交集。原12站、21来源、63组城市结果逐字段不变，原输入文件摘要不变。
- 本包每城只有一个映射站，无同城跨站合并；检查器实际比较站名集合，不仅假定该标志为false。样本最小值仅是已读表格中的最小值，不声称是全线路最快或每日保证时间。
- 仍只有一个来源读者；另一语言重算不代替第二位独立读者。独立复核子任务配额已终止，未重启、绕过或降低准入要求。
- 没有业务源码变化，未执行或宣称本批新的完整业务回归；未训练、读取封存题、替换模型、重新上传简历、线上登录复验、发布或推送GitHub。

本干线包剩余10站待处理：乐昌东、明港东、株洲西、正定机场、汨罗东、涿州东、耒阳西、英德西、邢台东、郴州西。涉及县域或跨站范围时仍需明确适用范围，不能仅将行政归属当作城市中心接驳条件。全国铁路及航空完整性、独立复核及生产连接仍未完成；全国目标没有缩小到这条干线。
