# 公开页面样本的查询日与乘车日期

2026-09-09，本地代码与回归记录，不是上线公告。

后续调整：普通推荐界面已隐藏查询日与乘车日期，后台仍保留并校验；本文下方双日期展示描述保留为当时实施记录，不再代表当前界面。另已增加五列弹窗适配，见 `PUBLIC_UI_POPUP_TABLE_20260909.md`。

## 已修复

原公开铁路页面入口只接受查询日等于乘车日期的样本。现在增加显式 `query_and_service_day_v2`，分别保存这两个日期，当前支持观察日后0—14天的所选乘车日期。旧 `query_service_day_v1` 仍要求两日相同，不静默迁移或改写历史来源。

新格式可在实际查询日用于投标前城市初筛；所选乘车日期留在原字段，不伪造发布日期，不当作整段运行图的生效日期或未来出行保证。来源的查询日必须与原页读取事件最早日期一致；UTC记录按北京时间转换，未记录秒数的旧式事件继续使用有日期的资料包，不补造时间。两个不同读者、原始文本及哈希、来源限制、具名车站、双向旅时、严格小于阈值等检查均保留。

新格式的复核期限最多为查询日后90天；第二读者晚一天核对不能把原观察日期顺延。旧格式保持原日期政策。未来查询记录仍拒绝，早于查询日、超过当前支持窗口、篡改可见日期、表格列角色不符等仍不通过；过期样本不成为航空后备依据。

前端原来也硬编码了旧日期格式，且不识别已验证六列停靠表的展示方法。本次一起接通两种明确的公开页面类型，分别校验页面地址、方法和来源类型，六列表保留查询车次与显示车次、不宣称二者等价。新格式在折叠依据中分别显示“查询日”和“乘车日期”，主卡片不增加日期堆叠；旧格式输出不变。
