# 自述授课事件与语义检索边界

## 本轮变更

`NarrativeTeachingEvents` 把有限语法内的课程、授课人、授课状态及同班学员对象关联到同一个事件。包括主动句、教学由本人完成的被动句、明确课程后紧接的主讲角色与结课回指。字段式档案另外兼容“完成情况”“本班对象”和“本人，独立完成全课讲授”。

所有字段、关系和事件保留 NFKC 原文及 Unicode 码点跨度，不生成新的履历句子。`verified=false` 始终保留：明确自述不是外部核验的资历。独立主讲标记只能来自源文本，不能靠模型相似度补齐。

程序不会把另一位老师的教学、学员结业、仅备课、计划课程或整份材料的否认说明当作本人已完成授课。课堂使用例题与“这份履历只是示例”区分处理；后者仍需拦截。多个课程事件和未解析条件不允许互相借授课对象、完成状态或独立主讲要求。

该模块是有界规则解析，不是任意自然语言理解或后训练；模型权重没有因此改变。未识别的句式仍可能漏荐，需要真实简历回放与新题检验。

## 与语义检索共享原文

Java 服务端从完整有效简历计算 `server_teaching_event_scopes`，仅发送完整、已完成的自述授课事件（每段不超过220码点）。Python worker 只对这些连续原文取向量，不把结构标记当成分数，更不决定讲师准入。

当旧检索器把其余段落标为不完整时，新事件使用 `source_teaching_events_v1` 独立范围；整篇仍然标为不完整，保留原因。无此契约时沿用旧检索路径。Java 收到评分后从完整源文本重新计算每个范围，拒绝变造的身份、跨度、删改否认、重复片段及超界文本。模型不拥有证据认证权限。

离线 `PosttrainingV2Probe` 与实际服务调用相同的原文范围生成和返回校验，不用测试专用的虚构分数补齐模型结果。

## 验证口径

新增固定合成解析测试目前包含两个领域的20个正向句式输入、20个反向输入、模拟材料/计划状态四个对偶输入，以及字段和跨度/协议校验，总364条断言；不是364道独立题。另有Python六个测试方法（含子测试）验证范围契约，旧字段54条和旧worker50个测试保持通过。

上述结果只证明所列规则和协议，不等于真实客户准确率。已看过的16题只作公开失败回归；最终指标、失败和19份真实简历的历史需求回放分别记录，不能将规则修复称为模型训练收益。

## 2026-09-08 实际验收：未达到替换门槛

已暴露16题从正例2/8提升到8/8，反例仍8/8拒荐。这是针对开发失败的规则修复，不是后训练收益。独立24项安全审查初始发现3项误判和1项漏判，修复后24项通过；另加入20条永久回归断言。

随后使用未参与训练、未修改题文或标签的封存32题（16正例、16反例），对固定Base、V4、V5量化权重运行同一冻结业务链：三个版本最终正例完整准入均为0/16，误准入0，worker错误2；128个候选文档实例均未产生新的授课事件范围。V5原始向量Top1从V4的3/16变为4/16，但worker Top1仍为5/16，**没有最终推荐收益**。错误、待核与漏荐均保留，不能合并成成功。

19份真实简历的8条历史合成需求回放中，三模型相关正需求准入/入选均6/7、相关教师—需求标签准入16/23、最终首位相关5/7。汇总相同不代表完整排序逐项相同；这不是新客户盲测。两条结构化协议对照三模型均2/2通过，只说明已识别结构的评分传递正确。

因此本版事件规则及V5未获生产替换批准。上游的事件/需求解析仍是瓶颈；下一步应将“候选事实抽取—主体/课程/状态关系—同源安全核验”分层，并输出可诊断的未解析原因，不能以继续增加相似词或提高向量分数替代授课事实。
