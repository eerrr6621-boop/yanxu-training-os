# M06 独立前端说明

## 使用

- 入口 `index.js` 导出 `async mount(root, context)`，返回可重复安全调用的清理函数。
- 宿主传入 `context.mode = 'demo'` 显示合成演示；`live` 或未明确指定 `demo` 均显示“统计口径已确定，正式数据尚未接入”。目前不调用任何 API。
- 建议通过现有本地 HTTP 服务打开 `web/modules/reports/demo.html`；追加 `?mode=live` 可验证正式数据未接入状态。浏览器通常禁止 `file://` 下的 ES module 导入。
- 只修改传入容器内内容。CSS 每个选择器均受 `.yx-reports` 容器限定；样式链接放在容器内。
- 监听 `context.signal`；已取消的挂载不改动页面。清理会移除本次监听、DOM、下载链接、延迟回收任务；同一容器重复挂载先卸载旧实例，异步导入返回后先检查是否卸载。

## 当前演示约定

- 规则标识 `DEMO-M06-1`、历史金额版本 `DEMO-FEE-1` 始终明确标为合成；筛选区域明确展示本次配置，不冒充正式规则版本。
- 依据最新用户决定，日期选择仅授课日期 `TEACHING` 与支付日期 `PAYMENT`。模型兼容枚举 `CONFIRMATION`，页面不提供正式可选入口。
- 四类课时分别统计、分别展示合计，不将同一事实的四类课时相加。默认按实际课时排名，也支持历史课酬排名。
- 默认包含 `CONFIRMED`、`ADJUSTMENT`，排除 `CANCELLED`、`SUPERSEDED`。演示筛选保留显式状态选项，供验证各类历史事实的影响；正式接入应使用获准规则。
- 调整事实表示有正负号的增减量。替换更正使用旧 `SUPERSEDED` 与新 `CONFIRMED` 事实表达；不会在统计时把替换金额误作增量，也不重新按费率定价。
- 默认竞争排名，同值共享名次并跳位；支持密集与顺序排名。同指标时按讲师编码升序稳定展示。
- 课程唯一数内部按数字 `courseId` 去重，并校验课程数字 ID 与课程编码的一一对应；页面和导出使用编码。跨组织课程总数取集合并集，不能直接相加。
- 演示模型用八位小数 BigInt 定点值累计，最多接受24位有效数字、8位小数；不使用浮点数累计金额或课时。展示至少两位小数，更多有效小数不舍入。输入未超过8位，合计不限制总位数。
- 讲师、机构、课程、记录、费用版本等编码遵循 `[A-Za-z0-9][A-Za-z0-9_.:-]*` 且最多96字符，不生成实名映射。
- 缺所选日期无法判断范围时明确报错；入选明细缺所选课时、历史费用或非 CNY 币种时停止汇总与导出。其他课时类别缺值时该类合计标“数据待补齐”，不做部分加总。

## 编码化导出

- 提供明细、讲师排名、机构汇总 CSV，以及统一 JSON 清单；不导出姓名、自由文本或数字业务 ID。
- CSV 包含规则版本、日期基准、课时类别、排名规则、状态、日期与组织范围等字段，文本使用引号与 UTF-8 BOM，不生成公式包装。
- 空结果 CSV 只有表头；JSON 清单仍保留完整规则、筛选范围、总量、四类课时合计及每种导出的 `rowCount`，请配套保存。
- Excel 直接打开 CSV 可能吞前导零或改变超15位数值；页面提示按文本导入编码及精确数值列。
- 演示 JSON 与 CSV 是独立演示格式，正式后端的导出协议由总控接入；规则字段已对齐 `hourBasis`、`rankMetric`。

## 默认月报入口（2026-09-21 追加）

- 用户已授权按建议直接采用默认月报格式，无须补交旧模板或样例。此授权只确定月报格式，不将合成演示视为正式业务数据。
- 统计口径前新增“统计月份”与上月、下月入口。默认月份取自 DEFAULT_FILTER，因此固定为合成样例所在的2026年09月，不随本机日期变为空结果。
- 选择月份自动覆盖完整自然月的开始及结束日期。手动改为非整月区间后，月份输入会清空，页面明确显示“自定义日期范围”；手动恢复一个完整自然月则会重新识别月份。恢复演示口径会恢复默认月份。
- 月份只接受0001-01至9999-12的严格年月形式，拒绝多余日期、扩展年份及无效月份。月底采用公历闰年规则，不依赖本地时区；上一月/下一月支持跨年，并在范围边界禁用对应方向。自定义范围下的快捷切月以开始日期所在月份为基准。
- 结果区新增“月度概览”，展示月份或自定义区间标题、原有总量和四类课时；突出“导出月度报表”按钮。空结果仍可导出完整报表，统计错误时不提供导出按钮。
- demo 模式按需动态导入 monthly-workbook.js，调用其 exportMonthlyWorkbook(result, model) 并下载返回的 Uint8Array 为 XLSX。整月文件名如 M06-合成月报-2026-09.xlsx，自定义范围在文件名中使用起止日期。
- 工作簿自身包含规则与范围说明，月报下载成功只提示已生成月度概览、讲师排名、机构汇总和明细对账；原有 CSV/JSON 保留为附加下载。
- 生成期间按钮禁用。异步生成期间若重新选择统计条件、重复挂载或取消挂载，旧结果不会下载或继续更新页面；对象 URL 和回收任务沿用清理机制。
- live 仍明确表示正式数据尚未接入，并补充月报格式已就绪；不调用演示工作簿生成器。
